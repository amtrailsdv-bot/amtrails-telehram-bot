AMTrails Telegram bot — инструкция

Что делает:
- отвечает приветствием на /start;
- показывает кнопки Каталог, Новинки, Связаться с менеджером, Instagram;
- показывает список команд в меню Telegram.

ВАЖНО: не отправляйте BOT_TOKEN никому и не публикуйте его в GitHub.

Для запуска на сервере:
1. Загрузите эти файлы в GitHub-репозиторий (main.py и requirements.txt).
2. Создайте Python-сервис на хостинге, подключив этот репозиторий.
3. Команда запуска: python main.py
4. Добавьте переменную окружения BOT_TOKEN со свежим токеном от @BotFather.
5. (Необязательно) Добавьте CATALOG_URL и MANAGER_URL — ссылки на каталог и менеджера.
6. Запустите сервис и проверьте /start в Telegram.

Для Manybot/Manychat этот код не нужен: он запускает бота напрямую через Telegram Bot API.
Не запускайте одновременно две копии этого же бота с polling, иначе они могут конфликтовать.
